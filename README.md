# Telegram Clone — frontend

Vite + React. Авторизация и сообщения работают через backend (`../server`). При локальном запуске Vite проксирует `/api` и `/socket.io` на `http://localhost:5000`.

## Запуск

Сначала поднимите backend (см. `../server/.env.example`), затем:

    npm install
    npm run dev

Откройте http://localhost:5173 и войдите по одноразовому коду из письма. Для нового email аккаунт создаётся автоматически. Пароли не используются.

Для другого backend задайте `VITE_API_URL` в `.env.local` по примеру `.env.example`. В production без этой переменной используется `https://telegram-copy-backend.onrender.com`.

## Сообщения

- Общий чат, личные диалоги, ответы с цитатой и переходом к исходному сообщению.
- Одна галочка: сообщение сохранено сервером. Две: собеседник открыл последние сообщения личного диалога в активной вкладке; в общем чате — их просмотрел хотя бы один другой участник. Собственный просмотр не учитывается. Подтверждения сохраняются после перезагрузки.
- Счётчики непрочитанных учитывают скрытые сообщения и очищенную историю.
- Фото и файлы до 10 МБ, в том числе без подписи. JPEG, PNG и WebP показываются в переписке; остальные файлы доступны для скачивания. Скачивание требует авторизации и доступа к сообщению.
- Новые сообщения сохраняют позицию при чтении истории; кнопка со стрелкой возвращает к последним. Подгрузка старых сообщений также сохраняет место.
- При ошибке редактирования введённая правка остаётся в поле. Неотправленное сообщение можно повторить или отменить вместе с вложением и ответом.
- «Избранное» — личный чат для заметок и файлов. Кнопка закладки рядом с сообщением или пункт «В избранное» в его меню сохраняет копию с именем автора. Копия остаётся доступной после удаления оригинала; другие пользователи её не видят.
- Закрепление сразу меняет порядок чатов, а при ошибке сохранения возвращает прежнее состояние. Сообщения приходят по Socket.IO; при недоступном WebSocket соединение пробует polling. Обычное новое сообщение обновляет переписку и список без повторной загрузки всех чатов.

Онлайн и последнее посещение обновляются через Socket.IO. Время хранится в базе и отображается по часовому поясу зрителя. Настройка приватности скрывает и онлайн, и последнее посещение в API и событиях. Для старых аккаунтов без сохранённой активности время появится после следующего подключения.

Демоверсия `/demo` работает на вымышленных данных в памяти, включая ответы и вложения; данные не отправляются на backend.

## Группы, поиск и уведомления

- «Создать группу»: до 100 участников, добавление по @нику или вступление по ссылке. Владелец назначает администраторов и передаёт владение. Администраторы управляют участниками и могут удалять чужие сообщения у всех; обычные участники — только свои. Новая ссылка приглашения заменяет предыдущую.
- Лупа в заголовке ищет текст и имена файлов по всей доступной истории, включая сообщения старше первых 50. Нажатие результата переходит к сообщению.
- Значок булавки закрепляет личный диалог, группу или общий чат. Закрепление сохраняется на сервере отдельно для каждого пользователя.
- Индикатор набора работает через Socket.IO и очищается при остановке, выходе и тайм-ауте. Настройка скрытия онлайна также скрывает набор текста.
- Кнопка микрофона записывает голосовое до трёх минут. Запись можно прослушать, удалить или отправить. Микрофон освобождается при остановке, отмене и закрытии чата. Ограничение вложения остаётся 10 МБ.
- Колокольчик открывает настройки уведомлений, звука и показа текста. Разрешение запрашивается только по нажатию. Уведомления приходят при открытой вкладке, включая свёрнутое окно; для полностью закрытого приложения доставка через Web Push не подключена. Собственные сообщения и сообщения открытого активного чата уведомления не создают.
- Запись и системные уведомления требуют поддержки браузера и защищённого контекста (HTTPS или localhost). Используются [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) и [Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API).

## Запуск проверок

В `tg-client` и `server` выполните `npm test`. В клиенте также выполните `npm run build`. Серверные тесты используют базу в памяти, а не настоящую MongoDB. Для новых функций нужно обновлять и frontend, и backend.

## Языки

Интерфейс доступен на русском, английском и узбекском. Переключатель языка находится внизу боковой панели и на страницах входа и регистрации; выбор сохраняется в браузере.

Чтобы добавить язык, создайте файл в `src/i18n/locales/` по образцу `en.js` и подключите его в `src/i18n/I18nProvider.jsx` (`DICTIONARIES` и `LANGUAGES`).

Сервер возвращает ошибки в виде `{ code, message, params }`: клиент переводит их по `code`, а `message` остаётся запасным текстом.
